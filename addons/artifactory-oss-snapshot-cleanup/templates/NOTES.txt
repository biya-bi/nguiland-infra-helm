=== Artifactory Snapshot Cleanup: {{ .Release.Name }} ===

1. Check the CronJob status:
   kubectl get cronjob {{ include "artifactory-oss-snapshot-cleanup.fullname" . }} -n {{ .Release.Namespace }}

2. View the current configuration:
   Target Artifactory: {{ .Values.artOssUrl }}
   Target Repository: {{ .Values.envMap.REPO }}
   Keep Strategy:     Last {{ .Values.envMap.KEEP }} builds
   Max Age:           {{ .Values.envMap.MAX_AGE_HOURS }} hours
   Dry Run Mode:      {{ .Values.envMap.DRY_RUN }}

3. Trigger a manual cleanup run now:
   kubectl create job --from=cronjob/{{ include "artifactory-oss-snapshot-cleanup.fullname" . }} {{ include "artifactory-oss-snapshot-cleanup.fullname" . }}-manual-$(date +%s) -n {{ .Release.Namespace }}

4. View logs of the latest run:
   kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }} --tail=50

5. Important Paths:
   Artifactory URL: {{ .Values.envMap.ART_URL }}
   Image Host:      {{ .Values.imagePullEndpoint }}

NOTE: If DRY_RUN is "true", no artifacts will be deleted. Check logs to see what *would* have happened.
