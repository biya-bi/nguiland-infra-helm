*******************************************************************************
*  Artifactory Safe Trash Cleanup: {{ .Release.Name }}
*******************************************************************************

1. Get the CronJob status:
   kubectl get cronjob {{ include "artifactory-oss-trash-cleanup.fullname" . }} -n {{ .Release.Namespace }}

2. Current Configuration Summary:
   Target Artifactory: {{ .Values.artOssUrl }}
   Trash Retention:    {{ .Values.envMap.MAX_TRASH_AGE_HOURS }} hours
   Schedule:           {{ .Values.schedule | quote }}
   Image:              {{ .Values.imagePullEndpoint }}/{{ .Values.image.repository }}:{{ .Values.image.tag }}

3. Trigger a manual cleanup run now:
   kubectl create job --from=cronjob/{{ include "artifactory-oss-trash-cleanup.fullname" . }} {{ include "artifactory-oss-trash-cleanup.fullname" . }}-manual-$(date +%s) -n {{ .Release.Namespace }}

4. View logs of the most recent run:
   kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }} --tail=100

5. Debugging Auth:
   Registry Secret:    {{ range .Values.imagePullSecrets }}{{ .name }} {{ end }}
   Artifactory Secret: {{ (index .Values.envSecrets 0).valueFrom.secretKeyRef.name }}

NOTE: The script identifies items in the Artifactory Trashcan older than {{ .Values.envMap.MAX_TRASH_AGE_HOURS }} hours and permanently deletes them using the Trashcan API.
